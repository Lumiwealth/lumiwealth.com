Build options strategies with LumiBot.

Learn how contract selection fits into an options trading strategy. LumiBot's options chain reference is the place to start when choosing expirations and strikes.

Read The Options Chain Guide

An options chain lets a strategy examine available contracts for an underlying asset. Define how the strategy chooses an expiration, strike and option type, and what it should do when the required contract or price is unavailable.

Use LumiBot's get_chain reference together with its order and backtesting documentation. Data sources and brokers have different coverage, so verify that your selected setup supports the contracts you want to test. A successful code run is only one part of checking a strategy.

Where to begin.

  1. Choose the underlying asset and write down the contract selection rules.
  2. Inspect the returned chain and select the exact expiration and strike your rules require.
  3. Test selection, entry and exits together, including dates when the desired contract is missing.
